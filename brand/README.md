# Agentsol logo

Original mark: a half sun rising on a horizon line, with one long ray pointing up (the direction an agent is guided in) and two short rays. Built from 5-unit strokes on a 64-unit grid, so it stays legible at 16 px.

| File | Use |
|---|---|
| `agentsol-mark.svg` | Mark on light backgrounds (ink + terracotta) |
| `agentsol-mark-dark.svg` | Mark on dark backgrounds (cream + light terracotta) |
| `agentsol-mark-tile.svg` | App icon / favicon tile (also `web/favicon.svg`) |
| `agentsol-wordmark.svg`, `agentsol-wordmark-dark.svg` | Mark + "Agentsol" name |

Colours: ink `#1c1b18`, cream `#f5f2ea`, terracotta `#d4612c` (light) / `#e0703a` (tile) / `#f08a55` (dark).
The wordmark uses live text in the site's system serif stack, so it renders slightly differently per system; convert to outlines before print or third-party use.
Not part of the npm package.
